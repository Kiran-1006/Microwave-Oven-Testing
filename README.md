# 🍽️ Microwave Oven Simulator

A simple and interactive **Python OOP project** that simulates different microwave oven brands and their available features.

## 📌 About The Project

This project demonstrates how **Object-Oriented Programming (OOP)** can be used to model a real-world device like a microwave oven.

The program allows the user to select a microwave brand, view its features, and perform different tasks such as:

- 🔥 Heating
- 🍳 Cooking
- ❄️ Defrosting
- 🧁 Baking
- 🔥 Grilling

Different microwave brands have different features, making the program more realistic.

## 🛠️ Technologies Used

- Python 🐍
- Object-Oriented Programming (OOP)
- `__init__()` Constructor
- Classes & Objects
- Instance Variables
- Methods
- Conditional Statements
- `match-case`
- `while` Loop
- `time` Module
- User Input

## 🎯 Learning Objectives

This project helps to understand:

- How classes and objects work in Python.
- How the __init__() constructor works.
- How instance variables store properties.
- How methods perform different operations.
- How OOP can be used in real-world applications.
- How match-case works.
- How loops and conditions work.
- How the time module can be used for countdowns.
